## 🔐 Safe and Secure

Security matters, especially when managing servers. This app uses a special security feature called **TOFU** (Trust On First Use). When you first connect to a server, it remembers that server's unique "fingerprint." If the fingerprint changes later (which could indicate tampering), the app warns you before connecting.

You can see all your trusted servers in a clear list, and you decide which ones to trust. This keeps your connections safe and private.

## 🛠️ Troubleshooting Tips

If something doesn't work right:

- **Can't connect?** Check that your server supports iLO 3 or iLO 4
- **App won't open?** Make sure you're on an Apple Silicon Mac (M1 or newer)
- **Connection drops?** Check your network connection and server status
- **Trust error?** If you see a warning about a trust fingerprint, verify your server hasn't been changed
